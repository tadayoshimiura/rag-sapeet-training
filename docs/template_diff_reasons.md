# 主要ファイルの変更理由（テンプレ差分）

## src/retrieval_graph/*
- ルーティングの挙動を日本語運用・KB前提に合わせるため。
- more-info を厳しめにして検索優先にする方針に合わせるため。

## src/shared/*
- Bedrock/KB/OpenSearch など新しい実行基盤に対応させるため。
- プロンプトや出力の共通処理を統一するため。

## configs/*
- Bedrock/OpenSearch/KB の設定値を明示し、運用を固定するため。
- System Prompt をJSONで集中管理するため。

## pipelines/*
- 問題生成/要約/動画処理など、業務要件のバッチ処理を実装するため。

## scripts/*
- 実行入口を分離し、運用・検証を簡単にするため。

## docs/*
- 運用ルールや実行手順を外部化し、判断を固定するため。

## tests/*
- 追加機能の最低限の動作確認を行うため。
