# scripts について

このフォルダは **実行入口（ラッパー）** です。処理本体は `pipelines/` や `src/` にあります。

## ディレクトリ構成

- `entry/`
  - 手動実行の入口（単体実行・検証用）
- `jobs/`
  - バッチ実行（複数ファイルの一括処理）
- `sync/`
  - S3との同期（upload / course_store など）
- `utils/`
  - 補助ツール（HTML抽出、Whisper文字起こしなど）

## 運用ルール

- ここには **処理ロジックを増やさない**。入口として最小限にする。
- 追加する場合は `pipelines/` や `src/` の共通モジュールを呼ぶ形にする。
- 同じ処理の入口が増えすぎないように注意する。
